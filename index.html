Firebase Realtime Database Setup

Connect your free Firebase Realtime Database to sync invoices, clients, and payments across your devices in real-time. (If left blank, InvoicePro runs seamlessly in high-speed LocalStorage mode).

Bandwidth Saver & Quota Shield Active & Optimized

To prevent exhausting Firebase's free Spark download limit (~360 MB/day), InvoicePro uses Delta Child Sync (only updated items are sent, not whole collections) and compresses images.

Quick Setup Guide:
  1. Go to console.firebase.google.com and create a project.
  2. Add a Web App to get your config object.
  3. In the left menu, click Build > Realtime Database > Create Database.
  4. Under Rules, set ".read": true, ".write": true (or with your auth rules).
